# Sage Lawn and Landscape, LLC — GitHub Pages Site

1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main`, and `/root`.
4. After deployment, replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in:
   - `index.html`
   - `about.html`
   - `services.html`
   - `gallery.html`
   - `contact.html`
   - `robots.txt`
   - `sitemap.xml`
5. Commit the changes.
6. Add the final GitHub Pages URL to Google Search Console and submit `sitemap.xml`.

The site is static HTML/CSS and does not require a server-side database.
